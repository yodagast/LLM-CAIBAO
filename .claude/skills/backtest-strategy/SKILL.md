# 回测交易策略

## 策略文件

所有回测脚本位于 `strategy/` 目录下：

| 文件 | 说明 |
|------|------|
| `backtest_hybrid_3in1.py` | **三分组合策略**（买入持有+区间交易+低价突破） |
| `backtest_compare_and_plot.py` | 多策略对比回测 + 曲线绘制 |
| `backtest_price_band_breakout.py` | 价格区间 + N日突破策略（单股票） |
| `backtest_multi_stock.py` | 多股票组合策略回测 |
| `backtest_zhonggai_etf.py` | 513050 固定阈值网格策略 |
| `backtest_zhonggai_20d_breakout.py` | 513050 20日波动突破策略 |
| `backtest_zhonggai_price_breakout.py` | 513050 N日价格突破策略 |

## 三分组合策略（推荐）

### 资金分配

每只股票投入 30,000 元，等分为 3 份（各 10,000 元）：

| 子策略 | 比例 | 说明 |
|--------|:---:|------|
| **A. 买入并持有** | 1/3 | 开盘买入，一直持有 |
| **B. 区间交易** | 1/3 | 低于限价买入全部，高于限价卖出全部 |
| **C. 低价突破** | 1/3 | N日最低+低于限价买入；N日最高或涨幅>20%卖出 |

### 参数配置

| 股票 | 买入限价 | 卖出底价 | 区间买入 | 区间卖出 |
|------|:-------:|:--------:|:--------:|:--------:|
| 五粮液(000858.SZ) | ≤75 | ≥65 | ≤75 | ≥150 |
| 招商银行(600036.SH) | ≤30 | ≥26 | ≤30 | ≥40 |
| 中概互联ETF(513050.SH) | ≤1.1 | ≥1.0 | ≤1.1 | ≥1.5 |

### 运行命令

```bash
# 三分组合回测 + 曲线图（默认N=5,20,60,120,250）
.venv/bin/python strategy/backtest_hybrid_3in1.py
```

| 股票 | 总收益率 | 年化 | 回撤 |
|------|:-------:|:---:|:---:|

### 子策略贡献（N=60）

| 股票 | 买入持有 | 区间交易 | 低价突破 |
|------|:-------:|:-------:|:-------:|
| 五粮液 | +113.21% | **+331.19%** | -3.15% |
| 招商银行 | +117.15% | **+308.64%** | +75.93% |
| 中概互联ETF | +11.57% | **+195.20%** | +70.99% |

> **结论**: 区间交易子策略贡献最大；低价突破策略在震荡/上升市（招行、中概）表现好，在单边趋势（五粮液）表现一般。
